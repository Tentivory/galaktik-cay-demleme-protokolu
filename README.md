# Galaktik Çay Demleme Protokolü

## Resmi Beyanname

Bu repository, insanlık tarihinin en kritik sorusuna cevap vermek üzere kurulmuştur: **Çay nasıl demlenir?**

Cevap basit değildir. Çay demlemek bir sanat değil, bir protokoldür. Bir bilimdir. Bir yaşam tarzıdır. Hatta galaksiler arası bir diplomasidir.

### Nasıl Çalışır?

1. Programı çalıştırırsınız.
2. Program size "Çay var mı?" diye sorar.
3. Eğer "var" derseniz, demleme başlar. 5 saniye bekletir (gerçek çay 5 dakika demlenir ama biz hızlıyız).
4. Eğer "yok" derseniz, program sizi kibarca dışarı atar ve "Çayınız olmadan buraya gelmeyin" der.
5. Her şey abartılı derecede ciddidir.

### Kurulum

```bash
python cay_protokolu.py
```

Python 3.x yeterlidir. Çay makinesi opsiyoneldir.

### Uyarı

Bu program gerçek çay demlemez. Sadece simüle eder. Eğer gerçek çay istiyorsanız, çaydanlığı ocağa koyun. Bu kod sizin yerinize yapmaz. Üzgünüz.

### Lisans

Bu proje MIT lisansı altındadır. Ama çayı paylaşmak zorundasınız. Paylaşmazsanız lisans geçersiz olur.
